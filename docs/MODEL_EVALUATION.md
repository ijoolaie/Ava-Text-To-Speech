## 2. معیارهای گفتاری (نیازمند مدل واقعی آموزش‌دیده — پروتکل آماده)

| معیار | روش | پذیرش هدف v0 |
| --- | --- | --- |
| وضوح کلام (Intelligibility) | WER با ASR فارسی روی ۱۰۰ جملهٔ تست vs متن مرجع | WER ≤ 25% |
| تلفظ | نرخ خطای واژه‌های حاوی اعداد/تاریخ از موتور زبان | ≥ 90% درست |
| طبیعی بودن (Naturalness) | MOS 1-5 با ≥ ۵ شنوندهٔ فارسی‌زبان، ۲۰ نمونه تصادفی | MOS ≥ 3.5 |
| Prosody | مقایسهٔ مدت مکث پس از علائم با جدول prosody | ±30% |
| ثبات گوینده | شباهت embedding گوینده بین جمله‌ها (استخراج) | قضاوت شنیداری |
| تأخیر | پ۹۵ زمان تولید جملهٔ ۳ ثانیه‌ای | ≤ 6s CPU، ≤ 1s GPU |

**قانون**: هیچ معیار خودکاری جایگزین ارزیابی انسانی نمی‌شود؛ مدل بدون MOS ثبت‌شده «کیفیت‌سنجی‌شده» اعلام نمی‌گردد.

## 3. وضعیت فعلی (صادقانه)

- مدل smoke (دادهٔ ساختگی tone-burst): فقط معیارهای ردیف ۱ معتبرند؛ صدای خروجی آن «گفتار» نیست و هرگز به‌عنوان محصول معرفی نمی‌شود.
- مدل Legacy (CC BY-NC): صدای واقعی فارسی دارد — برای مقایسهٔ کیفی و اثبات runtime؛ غیرتجاری.
- مدل واقعی AVA-N1: پس از آموزش با دادهٔ مجاز، جدول بالا کامل پر می‌شود و نتایج در همین سند ثبت می‌گردد.
